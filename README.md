# Free VLESS VPN — WT419 VPN

Free public VLESS VPN access provided by **WT419 VPN**.

This repository provides a public VLESS configuration for testing and personal use.

## VLESS Configuration

Copy the VLESS configuration from [`vless.txt`](./vless.txt) and import it into a compatible VPN client.

Compatible clients include:

* v2rayN
* v2rayNG
* Hiddify
* NekoBox
* sing-box
* Clash-compatible clients

## How to Connect

1. Open a compatible VLESS client.
2. Copy the configuration from `vless.txt`.
3. Import the VLESS configuration into your client.
4. Connect to the WT419 VPN server.
